One sentence: a one-star review of Earth from an alien tourist who has no laugh organ, yet still recommends the roast chicken.

## Run

Requires Node.js 22.18 or newer; TypeScript is stripped natively.

```sh
node main.ts
```

The program writes the entry as UTF-8 text to `/output/entry.txt`.
